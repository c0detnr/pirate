# Çizim stil rehberi

Her görsel üretim isteğine aşağıdaki STİL bloğu aynen eklenir.

## STİL
Hand-drawn 2D game illustration, NOT pixel art, NOT 3D render, NOT photo.
Bold dark-brown ink outlines of varying thickness (thick outer contour, thinner inner lines),
flat cel-shaded colors with one shadow tone and minimal highlights, slightly rough hand-inked
line quality, like a gritty comic / graphic-novel. Muted 18th-century pirate palette:
weathered browns, faded reds, dirty creams, sea blues, tarnished brass. Slightly exaggerated
proportions (big hands and boots, chunky silhouettes) but not chibi.
Background: perfectly flat solid magenta #FF00FF, no shadows on background, no ground, no text,
no border, no watermark. Single subject, fully inside frame, nothing cropped.

## Teknik kurallar
- Arka plan magenta (#FF00FF) üretilir, sonra şeffaf PNG'ye çevrilir (assets/art/raw → işlenmiş klasör).
- Karakterler: tam boy, ayaklar resmin altında aynı hizada, döndürme (turnaround) tek resimde: ön, sağ yan, arka.
- Silahlar (FPS): oyuncunun gözünden, ekranın sağ altından giren el + silah.
- Magenta karakterin kendisinde kullanılmaz.
